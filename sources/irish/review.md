## 2. Uncited or under-cited claims

1. **§0 reference-variety inference.** “This matches the user's own hand transcriptions … which show …” is an analysis of three user forms, not a cited dialect diagnosis, and is not marked `(unattested)`. *Ciara* in fact conflicts with the claimed Connacht system (§9.2).
2. **§2.1 name-shape generalization.** “Name-sized words are typically one or two syllables with a heavy first syllable” is not established by the cited orthography examples and is not marked `(unattested)`.
3. **§2.1 suffix generalization.** “Adjectival epithets in -ach add a final /əx/ syllable” is broader than the cited examples. The sources show examples and Munster stress behavior, not a productive epithet rule with this exact phonological output in all relevant dialects.
4. **§6 derivational semantics/productivity.** The labels “-ach ‘characterized by’,” “-án diminutive-augmentative,” “-óir agent noun,” and “-úil ‘like, -ly’,” plus their attachment conditions, are not supported by the cited phonology/orthography example lists. `wiki-irish-declension` supports gender/declension facts for -ín and -óir, but not the full derivational claims. These need grammatical/lexicographic citations or `(unattested)`.
5. **§6 noun+noun compound rule.** The digest correctly admits that modern noun+noun lenition is not covered, but then includes “Noun + noun compound, second element lenited” among “Ten productive patterns.” The row must remain explicitly provisional rather than being presented as a productive sourced pattern.
6. **§7 constructed-row provenance claim.** “Each [constructed row] was assembled from attested pieces and the note names the attested model” is false for *Rónán, Oisín, Úna, Máire, Séamus,* and *Dónall*: their notes name no model word. *Ní Bhriain* cites a mutation rule but does not provide an attested pronunciation model for the constructed name forms.
7. **§8.2 frequency labels.** They are collectively described as impressionistic and “unattested as a count,” which is acceptable, but individual assertions such as “every -ach epithet ends /əx/” and “/p/ low in native vocabulary” are factual generalizations beyond the cited text and should each carry a citation or explicit unattested marker.
8. **§10.1 “≈46 consonant phonemes.”** This is an arithmetic interpretation of the displayed Wikipedia table, not a source count. Mark it as a digest count rather than implying that the source states 46.
9. **§10.7 orthographic bridge.** “This alone converts most of a name's spelling between the two stages” is an uncited engineering inference and much stronger than the preceding spelling correspondences; morphology, apocope/syncope, and lexical replacement make “most” unsafe.

## 3. Rule/example consistency

### §3 rules with no test instantiation

The broad rule families are represented, but several directly stated mappings/triggers are not:

- **Lenition:** no row for /fˠ fʲ → ∅/; no audible fortis→lenis /l n/ row. The latter is expected to be null under the chosen two-way Connacht normalization, but the table should say that the test is intentionally inapplicable.
- **Eclipsis:** no test row for /p→b/, /t→d/, /k→ɡ/, /d→n/, /f→w~vʲ/, or vowel → /nV/. Existing rows cover /b→m/ (*mbláth*) and /ɡ→ŋ,ɲ/ (*ngasúr, ngeata*).
- **Other initial changes:** h-prothesis (*na héisc*) and t-prefixation (*an tsneachta*) are represented; **n-prothesis is not**.
- **Trigger inventory:** there is no test for possessive-triggered lenition/eclipsis, numeral-triggered mutation, article + feminine nominative lenition, article + masculine genitive lenition, or genitive-plural eclipsis.
- **Adjective agreement:** there is no row with an actually inflected/lenited attributive adjective such as *Máire Bhán* or a plural adjective contrast. Bare *bán* does not instantiate agreement.
- **Genitive/vocative:** represented by *mic, caisleáin,* and *a Sheáin*.
- **Compounding:** prefixal and fixed-compound lenition are represented; the noun+noun rule is represented only by the user-supplied, explicitly unsupported *Lasairchos*.

- The vocabulary is not semantically exact enough for the data:
  - *Ciara* has `dip:iə` but IPA `/ɪə/`; either normalize the IPA to /iə/ or add/define an allophonic tag policy.
  - *Diarmaid* has `seg:ɾˠ` but its cited IPA contains plain `r`.

### *Ciara* (§9.2) verification

The **initial consonant should be slender**, not broad, under the digest's own Connacht/standard transcription assumptions:

- `wiki-irish-orthography` §Vowels states *caol le caol*: consonants adjacent to ⟨e i⟩ are slender.
- `wiki-irish-phonology` §Vowel backness gives *ciall* /ciəl̪ˠ/ and says /iə/ occurs after a broad consonant only after word-initial /ɾˠ/.

Thus ⟨Ci-⟩ supports initial /c/, and broad /k/ in the user's /ˈkɪə.ɾˠə/ conflicts with the held source system. The full proposed /ˈciəɾˠə/ is still **an inference**, not an attested pronunciation of *Ciara* in a held source; the source containing the name lists no IPA. §9.2 should distinguish the verified **slender-initial diagnosis** from the inferred complete transcription.

## 4. Internal contradictions and missing CONFLICT lines

1. **Coda inventory contradiction.** §2.3 says “Wikipedia gives no exhaustive final-cluster list, but Green does, and it is short and closed”; §9.5 says “No exhaustive licit-final-cluster list exists in the open literature we hold” and that it was assembled by inspection. Green pp.55–56 plainly provides the inventory. §9.5 must be removed or rewritten to specify whatever Green does not cover (for example dialect variation or surface word-final realizations).
2. **Coda-neutralization contradiction.** §8.1 first says neutralization “should apply to labials and dorsals, not coronals,” then option 5 says “drop it on labials and dorsals, drop it in codas,” which includes coronals. The paper's result is gradient weakening, not a categorical rule in either form.
3. **/ɣ/ source contradiction.** §8.2 says /ɣ/ comes from “lenition/eclipsis of ⟨d g⟩”; §3.2 correctly maps eclipsed /d ɡ/ to nasals. Correct §8.2 to lenition only (plus radical/orthographic occurrences, if intended).
4. **/h/ target sentence is self-contradictory.** §8.2: “Every target has /h/ except Georgian (which has /h/) and Dutch (/ɦ/).” This must be rewritten as an actual target-by-target statement.
5. **“Every transcription” vs. normalized L/N system.** §8.2 says /l̪ˠ lʲ n̪ˠ nʲ/ are “present in every transcription,” but the digest and TSV themselves use /lˠ l̠ʲ n̠ʲ/ in source-copied forms. The intended alias normalization is stated in §1.1 but not actually applied consistently.
6. **Connacht /w/ CONFLICT not propagated to tests.** §1.1 and §3.1 explicitly distinguish pan-dialectal phonemic /w/ from Connacht medial/final [vˠ], but constructed `C` *Niamh* ends in /w/. Add a CONFLICT/note or correct the dialect/transcription level.
7. **Source-citation key conflict.** The digest invents abbreviated keys not present in `bib.md`. This is not a linguistic disagreement, but it violates the repository's citation contract throughout §8 and §10.
8. **Missing CONFLICT for *dubh*.** `wiki-irish-orthography` gives /d̪ˠʊw/ while the Connacht allophone passage gives [d̪ˠʊvˠ]. The row is marked `std`, so either is usable at a stated level, but the digest should record this as a scheme-vs.-dialect transcription conflict rather than silently use both.
9. **Missing CONFLICT/qualification for Old Irish inventory count.** §10.1 combines a reconstructed Wikipedia inventory, Pokorny's three-quality analysis, and uncertain sonorant values into a single “≈46” implementable inventory. The section records the two-way/three-way conflict later, but the count should be explicitly tied to the two-way Wikipedia analysis and not survive unchanged into the recommended three-way implementation.

## 5. Fitness for purpose

1. **The coda data are usable, but the digest tells the rule-writer both that they exist and that they do not.** Green's pp.55–56 table should be treated as the held baseline inventory, with dialect/surface caveats stated separately.
2. **The feature tags cannot safely drive deterministic test selection until their representation level is fixed.** Some tags name surface symbols, some collapse aliases, and `seg:w` can mean an underlying phoneme whose IPA surface is [vˠ]. Define “tag underlying phoneme” or “tag literal IPA segment,” then normalize every row.
3. **Modern source morphology is not yet an executable rule set.** §3 provides many triggers, but the test file covers only a minority. Add discriminating tests for each mutation mapping and the common name/epithet triggers before implementing source preprocessing.
4. **The constructed name set is too weak to function as regression truth.** Six constructed names have no model word at all; several others model only one substring. Keep them as provisional examples, not expected outputs, until replaced by speaker/user transcriptions or direct dictionary/audio evidence.
5. **The source-level/dialect-level distinction is underspecified.** `std` rows copy a pan-dialectal Wikipedia phonemic scheme, while `C/M/U` rows sometimes use allophones. A deterministic adapter needs one canonical input representation, with dialectal variants as separate fixtures rather than mixed conventions.
6. **§8 contains target-side assertions that are not reliably sourced here.** The source digest should catalogue Irish inputs; claims such as which targets “have no home” for a segment or what repair is “natural” should be checked in each target digest, not encoded from this file.
7. **Old Irish is not machine-ready.** §10 is a useful research digest, but there is no Old Irish TSV, no canonical inventory choice resolving two-way vs. three-way quality, and no Modern→Old derivation. The proposed eDIL lookup workflow is manual and lexical, so strand 5 cannot use the same deterministic rewrite architecture without a separate lexicon and tests.
8. **Malformed citation keys obstruct automated verification.** Normalize every key to `bib.md` before this digest is consumed by tooling or later reviewers.
