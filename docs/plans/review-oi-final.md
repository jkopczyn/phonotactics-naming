## Required fixes

1. **`src/strands/cli.py:251-255` — bare Old Irish `explain` does not actually force the promised RETRO path.** When `--orthography` is absent, the code sets `Entry.orthography` to the IPA argument and then performs normal lookup. If that text is also a lexicon key, lookup hits while the CLI prints that lookup “cannot hit”; for example, `strands explain mac --strand old-irish` reports the pure-RETRO note but returns `macc !ATTESTED`. This violates task 17/O-23 and makes the interface input-dependent in a way its own diagnostic denies. Force `run_entry_oi(..., lexicon={})` (or an equivalent explicit lookup disable) when `--orthography` is absent. **Failing test to add:** call `main(["explain", "mac", "--strand", "old-irish"])` and assert the output has `RETRO`, not `ATTESTED`, while retaining the `--orthography` note.

2. **`src/strands/cli.py:253-257`, `src/strands/cli.py:387-398` — `explain` leaks a traceback for valid multi-slot construction names.** `COLOUR`, `ADJ`, `OF`, and `COMPOUND` are accepted by `_constructions`, but `cmd_explain` supplies no secondary slots; `run_entry` raises `irish.MissingSlot`, which is neither translated in `cmd_explain` nor caught by `main`. `strands explain d̪ˠʊw --strand old-irish --orthography dubh --construction COLOUR` therefore prints a Python traceback, contrary to the CLI’s documented runtime-error boundary. Either reject constructions requiring unavailable slots as usage errors or catch `MissingSlot` and emit a normal diagnostic. **Failing test to add:** invoke that command through `main`, assert a defined nonzero return code and `"Traceback" not in stderr`.

3. **`src/strands/gallery.py:44-49`, `src/strands/gallery.py:118-127` — the formation review block does not render the required FER/COLOUR exemplars, and its COLOUR names are incorrectly lower-case.** The block only governs `Colm`, `Pádraig`, and `Culann`; consequently it never shows the design’s attested `Fer Diad` target and renders COLOUR as invented lower-case `dubcholum`, `dubphátraic`, and `dubchulann` rather than a capitalized `Dub-` name or the plan’s cited `Dubthach` target. This defeats the block’s purpose as the visual exercise of the formation templates and misses two of the required linguistic examples from design §7 / plan task 18 R31. Add the necessary governed/element fixtures (or a per-template case table) so FER is reviewed as `Fer Diad` and COLOUR against the cited capitalized colour compound. **Failing tests to add:** assert the formation block contains `Fer Diad` and a capitalized cited COLOUR result (for example `Dubthach`), and assert no COLOUR result begins with lower-case `dub`.
