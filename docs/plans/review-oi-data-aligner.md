# Required fixes

1. **`rules/old-irish-orthography.csv:55-56` — final ⟨-ae/-ai⟩ are reconstructed as schwa instead of the final vowel they spell.** Digest §10.1 explicitly contrasts final `marbae /ˈmarve/` and `marbai /ˈmarvi/`, and §10.2 §§40–41 says `-ae` writes final /e/ after a broad consonant while `-ai` writes final /i/. The table currently assigns both `ipa = ə`, so `carae` becomes `kaɾˠə` and `daltai` becomes `d̪ˠal̪ˠd̪ˠə`; this also misreconstructs lexicon forms including `abae`, `adarcae`, `anmae`, `fergae`, `lungae`, `Fíachrai`, and `snechtai`. Failing tests to add: `ipa("carae")[-1] == "e"` and `ipa("daltai")[-1] == "i"`.

2. **`src/strands/spelled.py:369-375` — every nonfinal unstressed short vowel is collapsed to /ə/, losing the digest's second unstressed phoneme /u/.** Digest §10.1 says medial ⟨a ai e i⟩ realize /ə/, but medial ⟨u o⟩ realize /u/, with the worked examples `lebor /ˈLʲevur/` and `domun /ˈdoṽun/`. The current code produces `lʲeβəɾˠ` and `d̪ˠoβ̃ən̪ˠ`, and likewise reconstructs the attested lexicon row `Colum` with schwa. Branch reduction by the written vowel class rather than assigning `ə` unconditionally. Failing tests to add: `ipa("lebor") == ("lʲ", "e", "β", "u", "ɾˠ")` and `ipa("domun") == ("d̪ˠ", "o", "β̃", "u", "n̪ˠ")`.

3. **`src/strands/spelled.py:347-351` — reconstruction implements only the ⟨i⟩ glide and treats Pokorny's §38 ⟨u⟩ glide as a full, then reduced, nucleus.** Digest §10.2 names `fiuss` as the worked u-glide example; current reconstruction returns `fʲiəsˠ`, inventing a schwa syllable. Under the strand's two-way-quality decision, the u-glide still must not become an independent /ə/ nucleus; represent its chosen phonetic value consistently with O-4 and test the digest example. A failing test should at minimum assert that `fiuss` has one nucleus/no schwa (for the current two-way representation, `("fʲ", "i", "sˠ")`).

4. **`src/strands/lexicon.py:103-108` — malformed TSV data rows are silently padded or truncated instead of failing schema validation.** An extra tenth cell is discarded with no finding, so accidental tabs can corrupt `note`/citation data while `strands check` exits 0; short rows are silently synthesized. The schema requirement applies to every row, not only the header. Preserve each row's actual cell count and emit a line-numbered `LEX_ROW_SHAPE` error unless it equals `len(LEXICON_COLUMNS)`. Failing tests to add: one nine-column header followed by an eight-cell row, and one followed by a ten-cell row; both must make `read_lexicon` fail and `check_lexicon_file` report `LEX_ROW_SHAPE`.

5. **`src/strands/spelled.py:212-218` — `SpelledWord.from_spelling` is not lossless for a capitalized vowel after written nasalization.** It records capitalization only from `text[0]`, so `SpelledWord.from_spelling("n-Ériu").render()` returns `n-ériu`, contradicting the class's lossless interface and O-32's required `n-Ériu` capitalization. Detect capitalization after the `n-` token when parsing, just as `render` already offsets past it. Failing test to add: `SpelledWord.from_spelling("n-Ériu").render() == "n-Ériu"`.
